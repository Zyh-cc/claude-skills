## 启动流程

### 第一步 + 第二步（并行执行）

**同时执行以下两个读取操作：**

**读取 progress.md 最新日期条目：**
```bash
gh api repos/Zyh-cc/AeroGround-Dataset/contents/docs/progress.md \
  --jq '.content' | base64 -d
```
拿到完整内容后，定位最后一个 `### 20xx-xx-xx` 标题，用 Read 工具 + offset 读从该行到文件末尾的全部内容。

**读取项目思路.md：**
使用 Read 工具完整读取：
`E:\清河\大学\科研\交通学院\毕设\工作台\docs\项目思路.md`

---

### 第三步：输出结构化状态摘要

读完后，向用户输出以下格式的摘要（不要啰嗦，每项一句话）：

```
## 当前状态摘要

**最近进展**（来自 progress.md 最新条目）
- [上次完成了什么]

**待确认问题**
- [列出 progress.md 中的待确认问题，若无则写"无"]

**工作计划**
- [列出 progress.md 中的下一步计划]

**研究方向**（来自项目思路.md）
- 当前阶段：[一句话]
- 核心创新点：[一句话概括]
- 当前卡点：[若有则列出，若无则写"无"]
```

输出摘要后，直接问：**"今天继续哪个方向？"**（若用户已说了任务则跳过，直接开始）

## 不要做

- 读当前对话里已经出现过的文件
- "理解背景"式地读其他相关文件
- 在摘要里复述大段原文，只提炼关键信息
