# 中国政策文件检索：用于学术论文背景写作

## 版本日志
| 版本 | 日期 | 变更内容 |
|------|------|----------|
| v1.0 | 2026-04-11 | 初始版本，来源：毕设论文§1.1低空经济政策检索失败复盘 |

## 问题场景

为中文学术论文（毕设/期刊）撰写政策背景段落，需要找到可正式引用的政府文件。
用户明确了主题（如"低空经济"），但初次搜索遗漏了最重要的顶层文件。

## 根因分析（血泪教训）

本次失败的四个根因：

| 根因 | 具体表现 | 后果 |
|------|---------|------|
| **年份锚定错误** | 搜索词写死"2023 2024 2025"，自然过滤当前年（2026）文件 | 遗漏刚发布一个月的十五五规划纲要 |
| **文档类型盲区** | 只搜"政策文件"，未想到"规划纲要" | 五年规划是最高层级，却是第一个漏掉的 |
| **层级从中间开始** | 从部委通知入手，而非从全国人大批准文件往下 | 找到了"工信部联重装〔2024〕52号"，却忽略了同等主题的NPC级文件 |
| **未感知当前时间** | 没有把"当前日期"纳入搜索策略 | 用户一句"十五五规划"立刻找到，说明关键词就在眼前 |

## 解决方案

### 标准流程：从顶层往下搜

**第一步：确定当前所在的五年规划周期**

```
当前日期 → 判断五年规划：
  2021-2025 → 十四五
  2026-2030 → 十五五（当前）
  2031-2035 → 十六五
```

搜索词模板：
```
{主题} {当前五年规划名称}规划纲要 2026
```

**第二步：按政策层级从高到低搜索**

```
层级1（最高）：全国人大批准的五年规划纲要
层级2：党中央文件（全会决定、中央经济工作会议）
层级3：国务院令、国务院/国务院办公厅文件（国发/国办发〔〕号）
层级4：多部委联合文件（工信部联重装〔〕号等）
层级5：单部委文件
层级6：地方文件（省市级）
```

**第三步：搜索关键词设计规则**

- 年份：用"当前年份"替代写死的历史年份，或不写年份
- 文件类型：同时搜"规划纲要"、"实施方案"、"通知"、"意见"
- 主题词：用主题的政策术语，不用技术术语

错误示例：`低空经济 感知 数据集 政策 2024`（技术术语+历史年份）
正确示例：`低空经济 五年规划 OR 规划纲要 OR 战略性新兴产业`

**第四步：每次搜索后检查结果的发布时间**

如果结果集中在2年前，明确补搜当前年份：
```
{主题} {当前年份} 正式发布 全文
```

### 推荐搜索顺序（4次搜索覆盖主题）

1. `{主题} 十五五规划纲要` — 找顶层规划
2. `{主题} 政府工作报告 {当前年份}` — 找最新表态
3. `{主题} 国务院令 OR 国务院文件 文号` — 找有文号的行政法规
4. `{主题} 工信部 OR 发改委 实施方案 文号` — 找部委落地文件

## 踩过的坑

| 坑 | 原因 | 解决 |
|----|------|------|
| 搜"政策文件"找不到规划纲要 | 规划纲要不叫"政策文件"，叫"规划纲要/发展规划" | 搜索词加"规划纲要"、"发展规划" |
| 搜2024年找不到2026年文件 | 写死年份 | 年份用变量，或同时搜"最新" |
| 找到部委文件以为已全面 | 不知道上面还有NPC级文件 | 先问"这个主题有没有写入五年规划" |
| 只搜英文找不到中文政策 | 中国政策文件首发均为中文 | 用中文关键词，一手来源是gov.cn/npc.gov.cn |

## 可引用文件的格式要求（中文毕设）

| 层级 | 引用格式示例 |
|------|------------|
| 五年规划纲要 | 国民经济和社会发展第十五个五年规划纲要[Z]. 北京: 人民出版社, 2026. |
| 国务院令 | 国务院. 无人驾驶航空器飞行管理暂行条例: 国令第761号[A]. 2023. |
| 多部委联合文件 | 工业和信息化部等. 通用航空装备创新应用实施方案（2024-2030年）: 工信部联重装〔2024〕52号[A]. 2024. |
