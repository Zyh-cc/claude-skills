# 对话日志写作：科研精简 + 生活有温度，两种语态

## 版本日志
| 版本 | 日期 | 变更内容 |
|------|------|----------|
| v1.0 | 2026-04-13 | 初始版本 |

## 问题场景

每次对话结束记日志，内容可能是科研/开发工作，也可能是日常生活（看电影、心情、喜欢的人、新运动……）。
两者需要完全不同的语态——一个精简归档，一个有温度像朋友在记录。

## 文件规范

- 路径：`E:\ClaudeCode\ClaudeLogs\YYYY-MM-DD.md`，**追加不覆盖**
- 同一天多次对话用 `---` 分隔
- 科研和生活内容**同一天分开两个区块**（各自独立，不混在一起）
- 先询问是否记录，再写

---

## 科研 / 开发内容：精简风格

**写什么**：决策 + 原因 + 结果 + 下一步阻塞点
**不写什么**：具体命令、中间报错、反复试错的过程、实现细节

格式：
```
工作目录：`路径`

- **做了什么决策**：为什么这么决定（一句话）
- **产出**：新脚本/功能/修复的核心是什么
- 下一步 / 阻塞点
```

示例：
```
工作目录：`E:\...\AeroGround-Dataset`

- **放弃 3D-BAT，改用 labelCloud**：UTM坐标WebGL精度崩溃 + ry定义不兼容，不值得绕过
- 新建 `apply_review.py`：FP 按坐标删除，FN 从 detail JSON 追加；bbox_idx 不可靠（置信度排序 ≠ 行号），用坐标匹配
- 下一步：开始正式审核 200 个预标注窗口
```

## 生活内容：有温度的朋友视角

**语态**：像一个朋友替另一个朋友记录——有情绪、有细节、读起来像在聊天，不像在归档。
**视角**：第三人称或第二人称均可，自然即可。
**长度**：不限，跟着感觉走，内容本身决定长短。

**写什么**：
- 看了什么电影 / 书 / 比赛 → 写他为什么被打动，或者没被打动
- 心情 / 心事 → 写那个情绪是什么感觉，不只是"有点难受"
- 喜欢的人 → 写那个具体的瞬间，而不是一个结论
- 学了新运动 → 写第一次做对那个动作是什么感受

**不写什么**：干燥的事件清单（"今天看了电影，很好看"）

示例（喜欢的人）：
```
今天在图书馆又碰到她了。她在靠窗的位置坐着，阳光正好打在她翻书的手上。
他没去打招呼，坐到了另一头，偷偷看了她两眼，然后假装很认真地看自己的书。
回去的路上一直在想要不要下次鼓起勇气说句话。
```

示例（新运动）：
```
今天第一次打网球。前半小时完全找不到感觉，球拍挥空三次算正常。
后来有个瞬间，球正好打在甜区，整个手感完全不一样——原来这就是"吃球"的感觉。
就那一下，他喜欢上这项运动了。
```
