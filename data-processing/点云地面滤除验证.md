# 点云地面滤除方法验证与可视化对比

## 版本日志
| 版本 | 日期 | 变更内容 |
|------|------|----------|
| v1.0 | 2026-04-08 | 初始版本 |

## 问题场景

在无人机点云数据处理中，需要对比多种地面滤除算法（CSF、RANSAC等）的效果，但：
1. 服务器端无法可视化点云，无法直观判断分割质量
2. 需要在本地用 open3d 目视验证多个方法的结果
3. 需要支持多帧快速切换对比，避免反复修改代码重新运行

## 解决方案

### 推荐方案：本地虚拟环境 + open3d 多帧可视化工具

**1. 创建本地虚拟环境**
```bash
cd 项目目录
python -m venv venv
.\venv\Scripts\activate  # Windows
pip install open3d numpy
```

**2. 开发可视化脚本**（支持多帧浏览）

关键功能：
- 加载原始点云和多种方法的分割结果
- 按 0/1/2/3 切换不同方法视图
- 按 E/W 切换帧（下一帧/上一帧）
- 自动着色：地面=棕色，非地面=绿色，原始=灰色

**3. VSCode 中运行**
- `Ctrl+Shift+P` → `Python: Select Interpreter` → 选择 `.\venv\Scripts\python.exe`
- 按 F5 运行脚本

**4. 验证标准**
- 正常：绿色=车辆/行人/建筑/树木，棕色=平坦路面
- 异常：绿色混入大量地面 或 棕色包含明显目标

### 备选方案：CloudCompare（GUI工具）

下载 CloudCompare，手动加载点云文件，但不支持批量对比和自动着色。

## 踩过的坑

| 坑 | 原因 | 解决 |
|----|------|------|
| open3d 读取中文路径 PCD 文件报 UnicodeDecodeError | Windows 中文路径编码问题 | 使用相对路径，在正确的工作目录下运行脚本 |
| 脚本输出中文乱码 | Windows 终端默认 GBK 编码 | 去掉 emoji，或在脚本开头设置 UTF-8 输出 |
| VSCode 运行脚本提示找不到文件 | 工作目录不对 | 确保在包含数据的目录下运行，或使用绝对路径 |
| CSF 简化版在某些帧不稳定 | 迭代次数太少（iter=100）导致收敛不充分 | 使用 CSF 原始参数（iter=500, res=0.5） |

## 关键发现

**三方法对比结果**（10帧测试）：
- **CSF 原始**（iter=500, res=0.5）：稳定，地面分割准确，推荐使用
- **CSF 简化**（iter=100, res=1.0）：速度快但不稳定，frame_000080 漏判 16.7% 地面点
- **RANSAC + 高度阈值**：速度最快但系统性偏低，不适用于复杂地形

**验证结论**：
- frame_000050 地面比例 35.6%（三方法一致）→ 真实场景特征，非算法问题
- frame_000080 CSF原始 49.9% vs CSF简化 33.2% → CSF简化不稳定
