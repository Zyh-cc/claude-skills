# 中文学术论文 AI 腔检查与修改流程

## 七类 AI 腔模式与修改方法

### 模式1：排比枚举（最典型）

**识别**：`其一…其二…其三`、`首先…其次…再次…最后`、`第一…第二…第三`

**先判断再修改**：

| 情形 | 判断依据 | 处理方式 |
|------|---------|---------|
| 凑数型排比 | 各项同质，去掉序号后可合并为一句；或内容可被"例如"替代 | 拆散为分段论证 |
| 分类型排比 | 各项属于同一逻辑框架下的**不同类别**，序号有实质区分功能 | **保留**，排比本身就是论证结构 |

**凑数型（应拆）举例**：
```
改前：其一，仿真类数据集遮挡标注依赖引擎接口；其二，真实数据集缺乏路侧基础设施；其三，无遮挡感知标注。
→ 三项均指向"遮挡标注缺失"，可按仿真/真实两类分两段展开。
```

**分类型（保留）举例**：
```
其一，协同增益量化依赖受控对照，在单视角数据集中根本不存在；
其二，跨传感器目标ID一致性是单端框架中没有对应概念的问题；
其三，"UAV能补多少路侧盲区"需要同时持有两个视角才能在逻辑上定义。
→ 三项均属"单端无法定义的研究问题"这一框架，各自是不同类型，保留排比结构更清晰。
```

**其余情形**：
- 两个对比项 → 用"在X上…在Y上…"或因果句式
- 保留序号的场合（如表格、图注）可例外

---

### 模式2：定义句开段

**识别**：段落第一句是"X是指…"或"X方法通过…实现了…"

**修改**：改为以**具体发现、失败案例、关键数字**开头。

**例**
```
改前：高质量标注数据集的有效性依赖系统化的质量评估机制。在标注一致性评估方面…

改后：标注质量的评估不能只靠主观审核。多标注员之间的标注一致性（IAA）通过 Cohen's Kappa 系数量化…
```

---

### 模式3："方面"/"上述"过度使用

**阈值**：
- `方面` ≤ 3 次（全文），且每次均不可替换
- `上述` ≤ 2 次，仅用于真正需要向上指代的场合

**修改**："在X方面" → 直接陈述 X；"上述研究" → 用具体名称或"这些工作"

---

### 模式4：句长均质化

**识别**：通读时节奏感均匀，几乎每句 25-35 字

**修改**：主动混入短句（8-15 字）打断节奏，尤其在段落末尾和转折处。

---

### 模式5：AI 过渡句（直接删除）

黑名单句式：
- "上述研究共同表明…"
- "由此可见…"
- "综上所述…"
- "这些工作为…奠定了基础"

过渡信息改为内嵌到下一段开头作为起因。

---

### 模式6：括号滥用

**规则**：
- ✅ 允许：引用编号 `[1]`、缩写首次定义 `激光雷达（LiDAR）`
- ❌ 禁止：术语解释括号、限定说明括号

---

### 模式7：空洞强调词（出现即删）

`至关重要`、`里程碑式`、`开创性地`、`显著提升了`（无数据支撑时）、`具有重要意义`、`不可或缺`

---

## 检查流程（逐步执行）

> **执行意图**：七步扫描结束后输出「问题清单」，等用户确认后再修改。不要边扫描边改稿。

```
Step 1：grep 排比触发词（其一/首先其次/第一第二）→ 先判断是"凑数型"还是"分类型"，凑数型拆散，分类型保留
Step 2：grep "方面" → 超过3处压缩
Step 3：grep "上述" → 超过2处替换为具体指代
Step 4：逐段检查第一句 → 定义句改为事实/发现/案例开头
Step 5：通读节奏 → 节奏过均匀则插入短句（段末或转折处）
Step 6：grep 黑名单词汇 → 删除或替换
Step 7：检查所有括号 → 非引用、非首次缩写的括号全部改写
```

## 输出格式与确认流程

七步检查完成后，**先汇报发现，再等用户确认，最后执行修改**。

### 汇报格式

> **发现 N 处问题：**
> 1. [模式类型] 触发词/位置 → 建议处理
> 2. …
>
> 全部修改？还是只改其中几处？

### 特殊情况

| 情况 | 处理 |
|------|------|
| 未发现问题 | 直接告知"未发现明显AI腔" |
| 分类型排比（判断保留） | 在问题清单中标注"✅ 分类型排比，建议保留"，不计入待修改项 |
| 用户说"直接改" | 无需确认，一次性输出修改后全文 |

---

## 质量验收标准

- 每段开头：至少50%的段落不以定义句开头
- `方面` ≤ 3次（全文）
- `上述` ≤ 2次（全文）
- 无**凑数型**排比枚举（分类型排比经判断可保留）
- 无黑名单词汇
- 段落内句子长度有明显节奏变化（最长/最短句字数比 > 2）
