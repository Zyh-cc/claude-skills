## 文件规范

- 路径：`E:\ClaudeCode\ClaudeLogs\YYYY-MM-DD.md`，追加不覆盖
- 同一天多次对话用 `---` 分隔
- 科研和生活内容**同一天分两个独立区块**
- 先询问是否记录，再写

---

## 科研 / 开发：精简风格

写**决策 + 原因 + 结果 + 下一步**，不写过程、命令、报错细节。

```
工作目录：`路径`

- **决策**：为什么（一句话）
- **产出**：核心是什么
- 下一步 / 阻塞点
```

---

## 生活：朋友视角，有温度

像一个朋友替另一个朋友记录——有情绪，有具体细节，读起来像在聊天。

- 看电影/书 → 写被什么打动，或没被打动
- 心情/心事 → 写那个情绪是什么感觉，不只是结论
- 喜欢的人 → 写那个具体瞬间
- 新运动/技能 → 写第一次做对时的感受

**避免**：干燥事件清单（"今天看了电影，很好看"）

示例（喜欢的人）：
> 今天在图书馆又碰到她了。她在靠窗的位置坐着，阳光正好打在她翻书的手上。他没去打招呼，坐到了另一头，偷偷看了她两眼，然后假装很认真地看自己的书。回去的路上一直在想要不要下次鼓起勇气说句话。

示例（新运动）：
> 今天第一次打网球。前半小时完全找不到感觉，球拍挥空三次算正常。后来有个瞬间，球正好打在甜区，手感完全不一样——原来这就是"吃球"的感觉。就那一下，他喜欢上这项运动了。
